## 1.3 程式化邊界

每一條候選都保留原始習慣文字、觸發條件、執行內容、證據護欄、停損／轉向條件與必要輸出。`deterministic_check` 可以在明確資料齊全時做機械檢查；`human_review` 必須交給人判斷；`assistive_prompt` 只提供提醒與問題，不直接做決策。
